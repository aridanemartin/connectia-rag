# connectia-rag-demo

Teacher-owned, Spanish-only RAG service for the Connectia course project. The
service is designed for Node.js and TypeScript with LangChain, Ollama, Qdrant,
SQLite, and Docker Compose on Ubuntu Server.

The repository is currently in the design phase. Implementation will begin after
review of the [approved design specification](docs/superpowers/specs/2026-08-15-connectia-rag-demo-design.md).

The completed README will include the numbered setup, indexing, activation,
question, preview, archive, testing, load-testing, and operations procedures
required by the specification.
